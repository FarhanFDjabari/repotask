1. Check `repo-task fact screens` for the established naming and file placement.
2. Create the screen in the module that owns the feature, matching its siblings.
3. Add the state holder next to it — see `repo-task fact viewmodels`.
4. Register the route with the project's navigation setup.
5. Handle every state the screen can be in: loading, empty, error, content.
6. Add the test the project expects for this layer.
